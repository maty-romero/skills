# skills

Agent skills for [opencode](https://opencode.ai) and compatible tools (Claude Code, Codex, Cursor).

## Available Skills

- **teach** — A stateful teaching workspace. Learn topics through structured lessons, projects, and learning records.

## Install

```bash
npx skills add maty-romero/skills
```

Restart your agent to pick up the new skill.
