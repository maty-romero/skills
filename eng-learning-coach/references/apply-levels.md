# Apply Levels

## Selection Rule

Choose the **smallest activity that can meaningfully validate the concept**.

Micro Exercise → Lab → Mini Project

Do not escalate automatically.

## Micro Exercise

**Purpose:** Validate one concept.

One main concept, minimal setup, fast feedback, usually 5–30 minutes.

> Can I make this concept work?

Example:

```text
PostgreSQL index
→ compare a query with and without an index
```

## Lab

**Purpose:** Use the concept in a realistic, controlled scenario.

Several interacting concepts, reproducible setup, observable behavior, usually 1–4 hours.

> Can I use this concept to solve a problem?

Example:

```text
Transactions
→ concurrent money transfers
→ observe isolation and locking behavior
```

## Mini Project

**Purpose:** Integrate the concept into a realistic system.

Use only when system-level integration creates meaningful learning.

Multiple components, design decisions, tradeoffs, several days of work.

> Can I build something useful with this?

Example:

```text
Kafka
→ event-driven banking system
```

## Independence Protocol

For meaningful implementation tasks:

Understand → Propose approach → Attempt → AI targeted help → Revise → AI review → Explain result

Increase AI assistance when blocked by mechanical complexity rather than conceptual difficulty.
